# SADEX Desktop

Desktop window for **SADEX — Formulas. Standards. Control.** by Ahmed Saadeh.

- **Download:** open the latest release under **Releases** and run `SADEX-Setup-x.y.z.exe`.
  Windows may show "Windows protected your PC" (not code-signed): **More info → Run anyway**.
- SADEX itself loads live from Claude, so app changes appear automatically.
- The window program updates itself from these releases and asks to restart when a new version is ready.
- Each PC signs in to Claude once (a free account works; use "Continue with email").
  SADEX must be shared with that email as Editor.
